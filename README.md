# UniMusic

Музыкальный плеер для Windows с VK и Яндекс Музыкой. Написан на Electron, React и TypeScript.

## Возможности

- Своя музыка, поиск, плейлисты, страницы исполнителей и альбомы.
- «Моя волна» Яндекса на главном экране.
- Общие плейлисты UniMusic с песнями из разных сервисов и локальными файлами.
- Orbs и фоновые огни, которые реагируют на звук. Можно менять режимы, расположение, цвета и чувствительность.
- Тексты песен рядом с обложкой.
- Автокэш только лайкнутых песен и воспроизведение скачанных файлов.
- Эквалайзер, горячие клавиши и работа в трее.
- Тёмная тема и системный Mica на поддерживаемых версиях Windows 11.

Настройки приложения, Яндекс Музыки и VK разделены. Вход в сервисы выполняется в самом приложении.

## Запуск из VS Code

Нужен Node.js версии 22.12 или новее. Рекомендуется Node.js 24 LTS.

```powershell
git clone https://github.com/monrch666/UniMusic.git
cd UniMusic
npm ci
npm run dev
```

Если PowerShell блокирует `npm.ps1`, используйте `npm.cmd` вместо `npm`.

## Сборка для Windows

```powershell
npm run dist
```

Для версии 0.7.6 файлы появятся в `release/0.7.6/`:

- `UniMusic-Portable-0.7.6-x64.exe` — запуск без установки.
- `UniMusic-Setup-0.7.6-x64.exe` — установщик.

В VS Code также есть задачи запуска и сборки в `.vscode/tasks.json`.

## Локальные данные

Сессии сервисов хранятся в профиле приложения и шифруются через Electron `safeStorage`. Токены не передаются в React и не сохраняются в `localStorage`.

Папку для скачанной музыки можно выбрать в настройках. Треки из «Моей волны» без лайка не скачиваются. Снятие лайка отменяет автоматическую загрузку, но не удаляет готовые файлы.

## Текущее состояние

Проект находится в разработке. Изменения на стороне VK и Яндекса могут влиять на вход и доступность отдельных треков. UniMusic не связан с этими сервисами.

Плейлисты UniMusic сохраняются локально, без облачной синхронизации. Редактирование плейлистов самого Яндекса пока не поддерживается. Готовые EXE пока без сертификата подписи издателя.

## Разработка

```powershell
npm run typecheck
npm test
```

Исходники интерфейса находятся в `src/`, главный процесс Electron и работа с сервисами — в `electron/`. Тесты — в `tests/`, сценарии проверки приложения — в `scripts/`.

Визуализация использует [thinking-orbs](https://github.com/Jakubantalik/thinking-orbs), иконки — [morphicons](https://github.com/guillermolg00/morphicons) и Lucide. Лицензии сторонних компонентов собраны в [THIRD_PARTY_NOTICES.txt](THIRD_PARTY_NOTICES.txt).
